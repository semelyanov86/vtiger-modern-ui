## Задача

Проверь и доведи модуль до выпуска по зависимостям, безопасности, доступности и скорости.
Не превращай установку темы в глобальное обновление библиотек CRM.

## Выполни

1. Актуальность, лицензии и известные проблемы собственных Vue/Vite/UI/icon/font зависимостей по
   официальным источникам. Обнови совместимые версии, зафиксируй lockfile, повтори сборку и
   затронутые проверки, сохрани notices. Без слепого принудительного major upgrade ради npm audit.
2. Карта глобальных библиотек хоста: jQuery, Bootstrap, Select2, jQuery UI и расширения. Опиши
   возможную будущую миграцию и блокирующие API. Не включай её в lifecycle ModernUI; новые компоненты
   не требуют второго глобального экземпляра этих библиотек.
3. Все PHP actions/views: авторизация, администраторские права, принадлежность личных настроек,
   CSRF на изменениях, валидация, ошибки без утечки секретов, параметры SQL, экранирование подписей,
   отсутствие произвольного выполнения. Защиту загрузки логотипа/импорта и обхода путей проверь
   отдельными запросами.
4. Кеш конфигурации/меню при смене пользователя/роли/языка и обновлении прав. Пользователь A не
   получает меню, данные или предпочтения B. Скрытые поля/модули не появляются через DOM, API
   конфигурации, preview или импорт.
5. Работа с текущим CSP хоста без ослабления защиты, без eval и CDN. Измерь bundle, число запросов,
   время появления рабочего интерфейса и задержки переходов относительно вида без темы; установи
   обоснованные бюджеты и исправь существенные регрессии. Замеры — в PACKAGE, не на watcher-сборке.
6. 30–50 переходов между списками/карточками/настройками, открытие/закрытие модальных окон,
   повторные AJAX-обновления: нет нарастающих подписок, запросов, узлов и заметного роста памяти.
7. Клавиатура: порядок фокуса, Escape, dropdown, альтернативы drag/drop, сохранение и отмена.
   Contrast, aria/labels, reduced motion, 200% zoom, RU/EN/DE, ширины 1440/1024/768/412, отсутствие
   недоступных кнопок.
8. Нескачанный JS chunk/CSS, 403/500 конфигурации, повреждённые настройки, отсутствие необязательного
   адаптера, истёкшая сессия: стандартный интерфейс, восстановление и администраторские настройки
   остаются достижимыми.
9. Словари RU/EN/DE: ключи, параметры, plural forms, locale UI-библиотеки, отсутствие непереведённых
   собственных строк, английский fallback, кеш между пользователями, полный немецкий текст и выход
   за границы кнопок.
10. Окружение разработки: подключённые каталоги read-only в каждом namespace PHP-FPM (`task crm:status`),
    dev server (если есть) не выставлен наружу, сборка и watcher не пишут вне репозитория темы,
    dev-настройки не попали в ZIP, `crm:link`/`crm:unlink` повторяемы, `git status` CRM не меняется.
11. Пересобери ZIP и выполни затронутые сценарии в PACKAGE на обоих стендах. Запиши реальные
    показатели и ограничения, отделяя проблемы ModernUI от дефектов хоста.

## Готовность

- Нет известных неисправленных проблем модуля, позволяющих обойти права/CSRF или выполнить код через
  настройки, импорт и загрузки.
- Нет требования заменить глобальные зависимости CRM или ослабить её защиту.
- Ресурсы, доступность, повторные переходы и восстановление реально проверены.
- dependencies.md и verification.md отражают фактическую сборку.
- Три языка проверены по `I18N.md`; невмешательство DEV и чистота PACKAGE подтверждены.
