# ModernUI 12 — Списки, фильтры и действия в облачной компоновке

Прочитай `PRIVATE.md`, `AGENTS.md`, `docs/COMMON.md`, `docs/PLAN.md`, `docs/DEVELOPMENT.md`,
`docs/I18N.md`, `docs/visual-parity.md`, `docs/design.md`, `docs/compatibility.md`, результаты 09–11.
Предусловие: 11 завершён. Область этапа — V03–V04, без реализации карточки/формы.

## Выполни

1. Переделай каркас списка по эталону: выбор представления/фильтра слева в toolbar, основное
   «Добавить» и дополнительные действия/пагинация в своих позициях, таблица ниже на всю рабочую
   ширину с заданными полями. Постоянного дерева «Списки» слева по умолчанию нет.
2. Сохрани все возможности старой панели: личные/общие фильтры, поиск/создание/редактирование фильтра,
   теги и действия расширений. Дай им раскрываемую панель/меню по эталону; отсутствие видимой
   панели не должно означать удаление функций. Сохрани настройку фильтра и URL при reload/Back.
3. Таблица: шапка, строки/плотность, выравнивание, checkboxes, сортировка, hover/selected,
   действия строки, пусто/loading/error, обрезка длинного значения с доступным полным текстом,
   горизонтальная прокрутка внутри таблицы. Сопоставь case/вес заголовков с эталоном, а не со
   старым запретом прописных букв. Недостающие в Open Source виды не имитируй пустыми кнопками.
4. Выбранные строки и массовые действия, поиск по колонкам и общий поиск, pagination/page size,
   экспорт, редактирование колонок и reference popup должны использовать штатное поведение.
   Не создавай вторую клиентскую копию бизнес-таблицы и не заменяй серверные фильтры общим API.
5. Accounts/Contacts/Leads и все inventory-списки; на dev-стенде — кастомизированные шаблоны,
   счётчики, цветные строки и дополнительные кнопки. Счётчики оформи в отдельной области без
   изменения значений. Нет фильтров/тегов/прав/избранного — отдельные состояния, без дыр в каркасе.
6. Сравни те же запросы, выбранные ID, пагинацию и доступность действий с v7; повторные AJAX-
   замены не возвращают sidebar и не дублируют обработчики. Проверь restricted user на чистом стенде.
7. Парные снимки и геометрия V03–V04 на сопоставимых наборах полей/данных, RU/EN/DE, узкие экраны
   и keyboard. Релевантные тесты, PACKAGE обоих стендов, возврат DEV, журнал и privacy.

## Готовность

- Списки узнаваемы как облачная композиция: фильтр в toolbar, правильные действия, полная рабочая
  ширина, нет оставленной постоянной панели v7. Структурные P1 этой области закрыты.
- Все доступные фильтры/теги/массовые действия/расширения достижимы, данные и права совпадают с v7.
- V/F подтверждены артефактами; текущий вид не назначен эталоном автоматически.
