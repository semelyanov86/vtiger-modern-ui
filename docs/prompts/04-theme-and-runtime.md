# ModernUI 04 — Внешний вид и совместная работа со старым интерфейсом

Рабочий каталог: корень этого репозитория. Прочитай `PRIVATE.md` (если есть), `AGENTS.md`, `docs/COMMON.md`, `docs/PLAN.md`, `docs/DEVELOPMENT.md`, `docs/I18N.md`,
design.md, architecture.md и environments.md.
Предусловие: этап 03 завершён. Если этап уже начат, продолжи по журналу.

## Задача

Создай полноценную основу оформления по облачному образцу и безопасный runtime для Vue-компонентов.
Интерфейс должен работать на обоих стендах после установки ZIP.

## Выполни

1. Дизайн-токены: поверхности, текст, акцент, границы, интервалы, радиусы, размеры элементов,
   z-index, плотность. Шрифты/значки с кириллицей, ä/ö/ü/ß и лицензиями упакуй локально.
   Значения настроек применяются через валидируемые токены.
2. Оформи основные элементы v7: кнопки, поля, подписи, вкладки, панели, таблицы, сообщения,
   выпадающие списки и модальные окна. Сохрани name/id/data-атрибуты, hidden/disabled/readonly,
   состояния ошибок, смысловые цвета и область клика.
3. Ограничь CSS активной темой. Изолируй стили Vue-библиотеки от Bootstrap CRM; без глобального reset.
   Проверь Teleport/порталы, Select2, datepicker, tooltip и popup вне корня компонента.
4. Runtime lifecycle для полной загрузки и AJAX/PJAX: идемпотентный init, unmount, подписки и таймеры,
   защита от повторного монтирования. Без постоянного сканирования всего DOM, если есть события.
5. Явные уровни: стандартный вид, совместимое оформление существующей страницы, собственный
   Vue-компонент. Определение возможностей предотвращает поломку неизвестного экрана. Не меняй DOM
   бизнес-форм ради декоративной сетки.
6. Сбой boot/недоступность JS/CSS/config: исходный экран рабочий, нет вечного loader и блокирующего
   overlay. Аварийный стандартный вид работает без Vue. Исходный элемент скрывается только после
   готовности замены.
7. Сравни реальные скриншоты с design.md на 1440/1024/768/412 px и RU/EN/DE, длинные подписи,
   клавиатуру и масштаб 200%. Исправь обрезания, перекрытия и потерю фокуса. Полноту карточек/форм
   не объявляй до этапа 07.
8. Итерации — на dev-стенде в DEV (`task crm:link`, watcher). Новые тексты сразу во все три словаря.
9. Пересобери ZIP, установи штатно на оба стенда (PACKAGE: чистый стенд и dev-стенд после
   `task crm:unlink`, затем возврат в DEV), выполни базовые сценарии. Замерь размер ресурсов и
   время включения относительно исходного вида.

## Готовность

- Основные элементы выглядят согласованно, токены настроек применяются runtime.
- Vue и jQuery не управляют одним DOM-поддеревом, повторные переходы не плодят обработчики.
- Выключенная тема сохраняет исходный вид; сбои ресурсов не блокируют работу CRM.
- Обе установки проходят базовую регрессию, скриншоты и замеры записаны.
- Три языка не ломают размеры/клавиатуру; watcher обновляет вид на dev-стенде без установки ZIP.
