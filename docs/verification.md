# Проверки ModernUI

Этап 01, 2026-11-01: матрица приёмки. Этапы 02–11 добавляют в §3 результаты (дата, версия Vtiger,
версия/SHA-256 ZIP, стенд, итог); частные подробности dev-стенда — в `PRIVATE.md`. Матрица — минимум,
обязательная матрица dev-стенда (`PRIVATE.md`) проверяется дополнительно и полностью.

Роли: **A** — администратор; **U** — пользователь с ограниченным профилем (часть модулей без
доступа); **G** — пользователь с глобальным просмотром; **A2** — второй администратор.
Стенды: **C** — чистый 8.4.0 (PACKAGE), **D** — dev-стенд в DEV, **DP** — dev-стенд в PACKAGE.
Способ: **E2E** — Playwright-сценарий в `tests/e2e/`; **CLI** — команда/скрипт; **M** — ручная проверка
по чек-листу с записью результата; **API** — запрос к действию ModernUI.
